## 1. 核心问题定位与重构目标

现有渲染画面呈现“网页/PPT 剪贴画感”的根本原因在于：
1. **元素过于平面呆滞**：角色如同单薄纸片，无四肢解剖结构与真实动作身段；
2. **缺乏空间景深**：所有视觉要素处于同一平视层级，缺少前景遮挡与远景空气透视；
3. **动画机械匀速**：位移大多为单一线性或正弦平移，缺少动画十二法则中的**动作前摇（Anticipation）**、**爆发穿透**与**过冲回弹（Overshoot）**；
4. **镜头缺乏张力**：缺少电影摄影机的推拉摇移、视差运动（Parallax）与冲击力震颤。

重构目标：**以工业级影视 Motion Graphics 为标准，彻底重构 22 幕动画的画面细节、角色身段与运动动力学**，实现动漫大片级别的视觉冲击力。

## 2. 三层影视景深与视差系统（Layered Depth & Parallax）

舞台保持 1920 × 1080 内部物理分辨率，并在渲染层级中强化三层空间结构：

```
[Camera Eye] ──> [前景遮挡层 (Parallax 1.4x)] ──> [中景动作主体 (Parallax 1.0x)] ──> [远景宏观环境 (Parallax 0.2x)]
```

### 2.1 前景遮挡层 (Foreground Framing - 1.4x 视差)
- **南天门与天宫（Scene 1, 5, 21）**：特大朱红盘龙金柱边缘穿插在镜头左右两侧，近景大片半透明流云高速滑过；
- **渡海长卷（Scene 2）**：镜头最下方扑溅而上的高动态水浪飞沫；
- **花果山仙境（Scene 4, 10）**：近景苍劲古松斜枝与垂挂青藤，形成天然取景画框；
- **蟠桃嘉宴（Scene 7–9）**：近景红木宴席转角、倾倒的金樽与纷飞的鲜嫩桃叶；
- **天宫大战（Scene 11–13, 20）**：金箍棒横扫时，被挑飞、旋转划过镜头边缘的破损天戈与碎盔。

### 2.2 中景核心主体层 (Midground Action - 1.0x 视差)
- **孙悟空动态人体与武生身段**：
  - 彻底摒弃直筒几何身躯，重塑具有**马步蓄力、弓步劈杀、腾空踏云、回身突刺**的动态人体结构；
  - 双手具有握棒手势与护腕细节，双腿呈现透视缩短（Foreshortening）；
  - 战袍披风与雉鸡双翎具备风力波浪形起伏褶皱与惯性滞后（Follow-Through）；
- **环境互动元素**：木筏随波峰波谷起伏颠簸、八卦炉火光映照在炉身暗金浮雕上、凌霄宝殿金柱在重击下产生断裂裂痕。

### 2.3 远景宏观构图层 (Background Vista - 0.2x 视差)
- **青绿金碧名山**：彻底移除单薄的折线锯齿山峦，采用传统工笔青绿山水，绘制具有光影受光面、背光阴面与斧劈皴纹理的雄奇峰峦；
- **浮空金阙群**：悬浮云海深处的层叠宫殿楼阁，辅以神圣的云隙金光（God Rays）；
- **空气透视隔层（Atmospheric Haze）**：在远山与中景之间加入淡金色或青蓝色的薄雾层，拉开空间深度。

## 3. Motion Graphics 运动动力学与非线性缓动系统

彻底替换简单线性 `p`（0–1），引入专业级缓动函数族：
- **前摇蓄力（Anticipation / Ease-In-Back）**：
  `anticipate(t) = t * t * (2.7 * t - 1.7)`（动作先向后微撤、下沉蓄劲）；
- **过冲回弹（Overshoot / Ease-Out-Back）**：
  `overshoot(t) = 1 + 2.7 * (t - 1)^3 + 1.7 * (t - 1)^2`（重击后冲出目标位置再弹性回缩）；
- **指数爆发（Explosive Strike / Ease-Out-Expo）**：
  `expoOut(t) = 1 - Math.pow(2, -10 * t)`（瞬间闪击、雷霆万钧）；
- **镜头动力学**：
  - 伴随挥棒出招，摄影机产生瞬间推近（Scale In）与定向平移冲力；
  - 重击命中帧（如 1612 帧）触发指数衰减震荡（Decaying Screen Shake）与动态动漫速度线（Anime Speedlines）。

## 4. 22 幕具体重构细节规划

1. **Scene 1–3（云海天宫、渡海求道）**：
   - 修复渡海山峦的矩形切口，重绘壮丽的波涛重峦长卷；
   - 木筏随浪头上下颠簸，孙悟空呈持篙迎风探身动态姿态。
2. **Scene 4（花果山自由称王）**：
   - 替换三角形几何山与方块瀑布，重绘带水汽飞溅、青松繁茂、仙石嶙峋的花果山水帘洞胜境；
   - 悟空呈金鸡独立背棍探海身段，披风烈烈作响。
3. **Scene 6–9（御马厩、蟠桃盛会）**：
   - 替换单调悬浮桃子，重绘铺满美玉佳酿、灵芝仙桃、九转金丹的盛宴全景；
   - 闹宴动作加入桌案掀翻、瓷器碎裂划破画面的动感特写。
4. **Scene 11–13（天兵压境第一棒）**：
   - 替换两簇死板排列的图标兵，重绘密布苍穹、枪如密林的十万天兵天将战阵；
   - 第一棒挥出时加入扇形金色流光拖尾、向镜头方向爆炸式掀飞的天兵与冲击气浪。
5. **Scene 16–19（八卦炉受炼与破炉）**：
   - 强化炉膛烈焰与炉身八卦金纹光斑，破炉时加入多层向外飞散穿透的青铜残片与动漫爆炸光芒。
6. **Scene 20–22（大闹凌霄与片名浮现）**：
   - 凌霄金柱坍塌做多角度倾倒，五彩神光如剑气撕裂虚空，最终汇聚为极具威仪的书法大字。
